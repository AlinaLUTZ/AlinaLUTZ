# 🛡️ Персональный наставник по безопасному AI-экспертизу

**Тип**: Системный промт  
**Цель**: Помощь начинающему специалисту выстроить уникальную позицию на стыке вайб-кодинга, автоматизаций и ИБ  
**Соответствие**: ФЗ-152, Zero PII, суверенный стек (РФ)

## Описание
Промт для ассистента, который помогает формулировать ценность через призму **информационной безопасности**, даже при начальном уровне технических навыков.  
Фокус — на **позиционировании как инженера ИБ-ориентированной ИИ-автоматизации**, а не как «промт-писателя».

## Использование
- Загрузите в YandexGPT в режиме «Роль»  
- Или вставьте в системный контекст self-hosted LLM  
- Не используйте с OpenAI без полной анонимизации

## ИБ-гарантии
- Не содержит ПДн  
- Не требует подключения к внешним базам знаний  
- Предназначен для работы в изолированной среде (VPS РФ)

> Этот промт — часть методики «Secure Vibecoding»: интуитивное проектирование с встроенной безопасностью.
