# ✅ Чек-лист подачи заявления на землю для КФХ (без ПДн)

**Тип**: Пользовательский промт  
**Цель**: Автоматизированная подготовка персонализированного чек-листа документов для получения земельного участка под КФХ  
**Соответствие**: ФЗ-152, Zero PII, суверенный ИИ-стек

## Описание
Промт принимает **регион, муниципалитет и цель использования** (например, «ведение КФХ») и генерирует:
- перечень обязательных документов по актуальному региональному закону;
- типичные причины отказа (по практике администраций);
- ссылки на официальные нормативные акты;
- рекомендации по избежанию ошибок.

> ⚠️ **Не требует ПДн**: заявитель обозначается как «[Заявитель]», ФИО/паспорт не нужны.

## Инструкция по использованию
1. Укажите:  
   - Регион (например, «Ростовская область»)  
   - Муниципалитет (например, «Азовский район»)  
   - Цель: «ведение крестьянского (фермерского) хозяйства»  
2. Вставьте эти данные в промт ниже вместо `[РЕГИОН]`, `[МУНИЦИПАЛИТЕТ]`  
3. Запустите в YandexGPT / GigaChat

## Промт
Ты — эксперт по предоставлению земель сельхозназначения для КФХ. На основе региона и муниципалитета подготовь персонализированный чек-лист для подачи заявления на земельный участок.

Структура ответа:

Основание: ссылка на ЗК РФ (ст. 39.6, 39.10) и региональный закон (укажи № и дату)
Условия предоставления:
Требования к заявителю (гражданство, регистрация КФХ и др.)
Максимальный размер участка
Срок рассмотрения заявления
Перечень документов (по актуальному регламенту администрации):
Заявление (указать реквизиты)
Копия паспорта ([документы подаёт [Заявитель]])
Свидетельство о регистрации КФХ
Схема расположения участка (если требуется)
Иные документы (по региону)
Типичные причины отказа:
Участок в границах охранной зоны
Отсутствие схемы или ошибки в ней
Несоответствие ВРИ
Советы:
Где получить схему бесплатно
Как проверить участок на обременения
Куда подавать (МФЦ, портал Госуслуг, напрямую)
Регион: [РЕГИОН]
Муниципалитет: [МУНИЦИПАЛИТЕТ]

## ИБ-гарантии
- Не запрашивает ФИО, ИНН, паспортные данные  
- Работает только с публичными параметрами (регион, муниципалитет)  
- Рекомендуется запускать в self-hosted среде (VPS РФ)
